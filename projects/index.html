  1. 2026

    ra-ng

    Radio astronomy, next generation. I want ra-ng to become the home for agentic radio astronomy, from first steps to science-grade images. The first piece is rang-core: a Rust core with a Python package and command line that flags, calibrates and images MeerKAT data.

    It contains ports of the solver from QuartiCal, the flagging strategies from Tricolour, the gridders from WSClean and ducc0, and a reader and writer for casacore tables. Each port has to reproduce the output of the original before it counts. There is also a new imager, GeMClean, and a set of Lean proofs about CLEAN.

    It is a tested research demonstrator, not something to run your observatory on, and it makes no claim of novelty. Several of the research questions ended in a null result, and those are documented just like the ones that worked. "Rang" is also Dutch for rank. Documentation and tutorials.

    RustPythonLean 4
  2. 2026

    s7commplus

    A pure Python library for S7CommPlus, the protocol that Siemens S7-1200 and S7-1500 PLCs use when the old PUT/GET access is switched off. It does protocol versions V1, V2 (with TLS) and V3, reads and writes optimized data blocks by tag name, has sync and asyncio clients, and ships a server emulator for testing. It is tested against a real S7-1200, an S7-1500 and PLCSIM Advanced. Documentation.

    Python
  3. 2026

    python-snap7 3.4

    Thirteen years in, python-snap7 no longer wraps the snap7 C library. It is pure Python now, with no native dependencies, and has close to 900 stars on GitHub. It speaks the classic S7 protocol. For everything newer there is s7commplus.

    Python
  4. 2026

    lean-s7 and lean-s7commplus

    The same two protocols again, this time in Lean 4. I use them to learn Lean and to get machine-checked proofs of the parts that are easy to get wrong: packet decoding, round trips and length fields. Running them against the Python libraries shows where the two disagree.

    Lean 4

    ha-s7

    A Home Assistant integration for Siemens S7 PLCs. Tags on the PLC show up as sensors, switches and numbers. It uses python-snap7 for the older controllers and s7commplus for the newer ones.

    PythonHome Assistant
  6. 2026

    Poing

    A music workstation built around AI. Drop in a song and Poing shows how it is put together: stems, sections, chords and lyrics. You can then replace any stem or section from a prompt or a reference sample, and play the result with instruments and effects. The models are open and run on your own machine. It is built on Makepad and in early development. Poing started in 2025 as a MusicGen audio plugin and is named after the classic Dutch track.

    RustMakepadlocal AI models
  7. 2026

    omalaka

    Open machine translation for Namibian languages. Omalaka is Oshiwambo for "languages". None of the well known translation services or open models handles Oshikwanyama or Oshindonga well. omalaka fine-tunes open models on openly licensed data, starting with those two into English. The pipeline works, but no model is released yet because there is not enough open training data. If you can help with that, please get in touch.

    PythonPyTorch
